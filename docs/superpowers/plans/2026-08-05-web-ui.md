# Web UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a read-only, server-rendered `GET /` page to `arxiv-serve` that lets you browse live recommendations with a filter form (top/min_score/cat/days), instead of reading raw JSON or `/digest.md`.

**Architecture:** `create_app` in `server.py` gains one new route that parses the same query params as `/recommend`, calls `recommend.recommend()` directly, and renders the results with Jinja2 into a single `index.html` template. A small hand-written `style.css` is served via `StaticFiles`. No JS, no new DB writes, no auth.

**Tech Stack:** Python 3.11+, uv, FastAPI, Jinja2 (new dependency), existing `recommend.py` scoring, pytest + FastAPI `TestClient` (httpx, new dev dependency)

## Global Constraints

- Use `uv run` for all Python commands — never `python` directly
- Read-only: no DB writes, no mark-as-seen, no fetch-on-demand triggers from the UI
- Local network only: no auth, no HTTPS
- No JS, no htmx — full page reload per filter change (spec explicitly defers htmx to a later upgrade)
- Reuses `recommend.recommend()` as-is — do not duplicate scoring logic in the route
- Empty results (e.g. no centroid yet) render an empty state, never a 500

Inside `create_app`, right after `app.state.s2_client = S2Client(...)` (around line 31), mount static files and add the route:

```python
    app.mount("/static", StaticFiles(directory=str(PACKAGE_ROOT / "static")), name="static")

    # `cat` is a single comma-separated string here (not /recommend's repeated
    # list param) because a plain HTML text input can't submit a repeated
    # query key — same filter, form-friendly wire format.
    @app.get("/", response_class=None)
    def index(
        request: Request,
        top: int = Query(15, ge=1, le=200),
        min_score: float = Query(0.0, ge=-1.0, le=1.0),
        cat: str = Query("", description="Comma-separated category codes"),
        days: int | None = Query(None, ge=1),
    ):
        categories = [c.strip() for c in cat.split(",") if c.strip()] or None
        conn = get_conn()
        try:
            results = recommend.recommend(
                conn, top=top, min_score=min_score, categories=categories, days=days
            )
        finally:
            conn.close()
        return templates.TemplateResponse(
            request,
            "index.html",
            {
                "recs": results,
                "top": top,
                "min_score": min_score,
                "cat": categories or [],
                "days": days,
                "error": None,
            },
        )
```

Note: `get_conn` is already defined earlier in `create_app` (existing helper used by `/status`, `/recommend`, etc.) — the new route reuses it rather than redefining a connection helper.

## What's Not In Scope

(carried over from the design spec — do not implement in this plan)

- Mark-as-seen/dismiss actions, or any DB writes from the UI
- "Similar papers" browsing or fetch-on-demand triggers from the browser
- Auth, HTTPS, or remote/away-from-home access
- htmx or any partial-reload interactivity
- Styling beyond plain readable CSS
